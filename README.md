# Sales Analytics & Business Intelligence Dashboard

### Microsoft Excel | Power Query | Power Pivot | Data Modeling | Data Visualization

## Project Overview

This project presents an end-to-end sales data analytics solution developed using Microsoft Excel and its Business Intelligence tools.

The project transforms raw company sales data into a structured data model and an analytical dashboard to support sales performance analysis and data-driven decision-making.

The workflow covers data cleaning, transformation, monthly data consolidation, dimensional modeling, measure development, PivotTable analysis, and dashboard creation.

## Project Objectives

- Transform raw company data into a structured analytical dataset.
- Consolidate monthly sales data into a unified table.
- Build a relational data model using Power Pivot.
- Develop analytical measures to support sales reporting.
- Analyze business data using PivotTables.
- Present analytical results through an Excel dashboard.

## Data Preparation & Transformation

### 1. Data Cleaning

Imported raw company data into Power Query and performed data cleaning and transformation to prepare the dataset for analysis.

### 2. Monthly Sales Consolidation

Used Power Query's **Transform File** functionality to process and consolidate monthly sales data into a unified table named `Sales Monthly`.

This step established a structured dataset for subsequent modeling and analysis.

### 3. Data Model Development

Organized the data into a sales table and supporting dimension tables:

| Table | Purpose |
|---|---|
| `Sales Monthly` | Consolidated monthly sales data |
| `DimCustomer` | Customer dimension |
| `DimProduct` | Product dimension |
| `DimRegions` | Region dimension |

Used Power Pivot to establish relationships between the tables and create a relational model for analytical reporting.

### 4. Measures & PivotTable Analysis

Developed analytical measures and used PivotTables to summarize and explore data from the model.

These components provided the analytical foundation for the dashboard.

### 5. Dashboard Development

Designed an Excel dashboard to visualize analytical results and communicate sales-related information in a clear and accessible format.

## Data Analytics Workflow
